# User Stories

## US01 - Registreren

Als nieuwe student
wil ik een account kunnen registreren
zodat ik toegang kan krijgen tot het lesplatform.

Prioriteit: Must
Tijdsindicatie: 1,5 uur



## US02 Inloggen en uitloggen

Als gebruiker wil ik kunnen inloggen en uitloggen zodat ik veilig gebruik kan maken van mijn account.

Prioriteit: Must have
Tijdsindicatie: 2 uur

Acceptatiecriteria:

De gebruiker kan inloggen met e-mail en wachtwoord.
Bij verkeerde gegevens komt er een foutmelding.
Na het inloggen wordt de gebruiker doorgestuurd naar het lessenoverzicht.
De gebruiker kan uitloggen en de sessie wordt dan gestopt.

## US03 Lessenoverzicht bekijken

Als gebruiker wil ik een overzicht van de lessen kunnen zien zodat ik makkelijk een les kan kiezen.

Prioriteit: Must have
Tijdsindicatie: 1,5 uur

Acceptatiecriteria:

De lessen worden uit de database gehaald.
De titel van iedere les wordt weergegeven.
De gebruiker kan vanuit het overzicht een les openen.
Als er geen lessen zijn wordt dit aangegeven.

## US04 Lesdetails bekijken

Als gebruiker wil ik een les kunnen openen zodat ik de volledige inhoud van de les kan bekijken.

Prioriteit: Must have
Tijdsindicatie: 1,5 uur

Acceptatiecriteria:

De titel en inhoud van de les worden weergegeven.
De juiste les wordt uit de database gehaald.
De gebruiker kan terug naar het lessenoverzicht.
Als een les niet bestaat wordt een foutmelding getoond.

## US05 Lessen beheren als docent

Als docent wil ik lessen kunnen toevoegen, aanpassen en verwijderen zodat ik het lesmateriaal kan beheren.

Prioriteit: Must have
Tijdsindicatie: 3 uur

Acceptatiecriteria:

Alleen een docent kan lessen beheren.
Een docent kan een nieuwe les toevoegen.
Een docent kan een bestaande les aanpassen.
Een docent kan een les verwijderen.
Titel en inhoud mogen niet leeg zijn.
De wijzigingen worden opgeslagen in de database.

## US06 Opmerkingen plaatsen bij lessen

Als gebruiker wil ik een opmerking bij een les kunnen plaatsen zodat ik een vraag of reactie kan achterlaten.

Prioriteit: Should have
Tijdsindicatie: 2 uur

Acceptatiecriteria:

Alleen ingelogde gebruikers kunnen een opmerking plaatsen.
Een opmerking hoort bij een specifieke les.
Een lege opmerking kan niet worden geplaatst.
De naam van de gebruiker wordt bij de opmerking weergegeven.
De opmerking wordt opgeslagen in de database.

## US07 Informatiekanaal bekijken

Als gebruiker wil ik informatieberichten kunnen bekijken zodat ik op de hoogte blijf van belangrijke informatie.

Prioriteit: Should have
Tijdsindicatie: 1 uur

Acceptatiecriteria:

De gebruiker kan het informatiekanaal openen.
De berichten worden uit de database gehaald.
De titel, inhoud en datum worden weergegeven.
Nieuwe berichten staan bovenaan.

## US08 Informatieberichten beheren als docent

Als docent wil ik informatieberichten kunnen toevoegen, aanpassen en verwijderen zodat ik gebruikers informatie kan geven.

Prioriteit: Should have
Tijdsindicatie: 2 uur

Acceptatiecriteria:

Alleen een docent kan berichten beheren.
Een docent kan berichten toevoegen.
Een docent kan berichten aanpassen.
Een docent kan berichten verwijderen.
De wijzigingen worden opgeslagen in de database.

## US09 Algemene voorwaarden bekijken en accepteren

Als gebruiker wil ik de algemene voorwaarden kunnen bekijken en accepteren zodat ik weet waarmee ik akkoord ga bij het gebruiken van de website.

Prioriteit: Must have
Tijdsindicatie: 1,5 uur

Acceptatiecriteria:

De algemene voorwaarden zijn te bekijken op de website.
Tijdens het registreren moet de gebruiker akkoord gaan.
Zonder akkoord kan de gebruiker zich niet registreren.
Het akkoord wordt opgeslagen in de database.
